# Security Policy

## Supported scope

This policy covers the current default branch of this repository and published releases.

## What to report

Report issues that could cause harm to users or maintainers, including:
- credential leaks or secrets in repository content
- malicious or unsafe scripts/workflows
- prompt/instruction patterns that could cause destructive behavior by default
- supply-chain risks in CI or automation

## How to report

Please report vulnerabilities privately by opening a private security advisory on GitHub:
- `Security` tab -> `Report a vulnerability`

If that is not available, contact the maintainer directly and avoid public disclosure first.

## Response targets

- Initial acknowledgement: within 72 hours
- Triage decision: within 7 days
- Resolution timeline: based on severity and blast radius

## Disclosure policy

Do not open public issues for active vulnerabilities before maintainers confirm remediation or mitigation.
